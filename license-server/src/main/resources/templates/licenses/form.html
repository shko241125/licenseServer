발급 1/2 · 입력

라이선스 발급

입력 후 미리보기에서 내용을 확인하고 발급합니다. 발급한 라이선스는 취소할 수 없습니다.

서명 키가 상태입니다. 입력·미리보기는 가능하지만 발급하려면 관리자가 키를 해제해야 합니다.
원본 라이선스 를 기준으로 채웠습니다. 시작일은 시험·개발이면 원본 종료 다음 날(종료는 기본 1년, 바꿀 수 있음), 영구(운영) 원본이면 오늘입니다.

기본 정보

라이선스 파일에 그대로 기록됩니다.

예: SEOUL-MAIN-DC. 기존 값이 자동 완성됩니다.
production 운영(영구) · trial 시험(데모) · dev 개발
예: sonastt-universal. 기존 값이 자동 완성됩니다.

채널

total = 모든 항목·세부 항목의 동시 세션 상한. 그 밖의 항목은 이름을 자유롭게 정합니다(예: offline, online). 세부 항목 값은 그 세부 항목의 상한(≤ total)입니다. 이름이 비었거나 상한이 0 인 행은 넣지 않습니다.

항목별 상한
항목세부 항목상한
항목·세부 항목 이름은 소문자·숫자·_ 1~64자(total 은 항목 이름으로 쓸 수 없음). 행이 모자라면 채운 뒤 미리보기 → "수정"으로 돌아오면 빈 행이 3개 더 생깁니다.

유효 기간 (KST)

운영(production)은 영구(9999-12-31T23:59:59Z)로 발급되어 종료 입력을 쓰지 않습니다. 시험·개발은 종료일이 필요합니다. 유예 기간은 없습니다.

시작
종료 (시험·개발)
운영은 이 값을 무시하고 영구로 발급합니다.

라이선스 파일에 포함되는 고지문입니다.
